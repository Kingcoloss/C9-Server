# ตัวละครจากไฟล์ (VRoid + Mixamo)

วางไฟล์ไว้ในโฟลเดอร์นี้ เกมจะโหลดเองตอนเริ่ม ไม่ต้องเปิดหน้าต่าง import ของ Godot
ถ้าไม่มีไฟล์ เกมจะใช้ตัวละครรูปทรงพื้นฐานเหมือนเดิม (กด F3 ในเกมเพื่อสลับสองแบบ)

```
godot/characters/
├── player.vrm            ตัวละคร (VRoid Studio ส่งออกเป็น VRM 0.0 หรือ 1.0 ได้ทั้งคู่)
├── anim_map.json         (ไม่ใส่ก็ได้) กำหนดเองว่าไฟล์ไหนใช้กับท่าไหน
└── anims/
    ├── sword and shield idle.fbx
    ├── sword and shield run.fbx
    └── ...               ท่าจาก Mixamo (ชุด Sword And Shield Pack)
```

## 1. ตัวละครจาก VRoid Studio

1. สร้างตัวละครใน VRoid Studio
2. เมนู Camera/Exporter > Export as VRM แล้วบันทึกเป็น `player.vrm` ในโฟลเดอร์นี้
3. ถ้ายังไม่มีตัวละครของเอง ใช้ไฟล์ Mixamo ที่มีผิว (เช่น Paladin, Download แบบ With Skin) ชั่วคราวได้ ตั้งชื่อ `player.fbx`

ถ้ามีหลายไฟล์ เกมจะเลือกไฟล์ที่ชื่อขึ้นต้นด้วย `player` ก่อน แล้วค่อยเลือกตามนามสกุล .vrm > .glb > .fbx

## 2. ท่าจาก Mixamo

1. เข้า mixamo.com ค้นหา "Sword And Shield Pack" กด Download
2. ตั้งค่า: Format = FBX Binary(.fbx), Skin = Without Skin, Frames per Second = 30, Keyframe Reduction = none
3. แตกไฟล์ zip แล้วย้ายไฟล์ .fbx ทั้งหมดมาไว้ใน `anims/`
4. ชุดดาบโล่ไม่มีท่ากลิ้ง ถ้าอยากได้ให้ค้นหา "Stand To Roll" หรือ "Sprinting Forward Roll" แล้วโหลดแบบเดียวกัน (ถ้ามีช่อง In Place ให้ติ๊ก)

ไฟล์ท่าแต่ละไฟล์ถูกแปลงลงโครงกระดูกของตัวละครตอนเริ่มเกม (retarget) โดยเทียบทิศของแขนขาในท่า T
จึงใช้กับโมเดล VRoid ที่สัดส่วนต่างจากหุ่น Mixamo ได้ ตำแหน่งตัวละครมาจาก Sim เสมอ การเคลื่อนที่ไปข้างหน้าในไฟล์ท่าจึงถูกตัดทิ้ง

## 3. ท่าไหนใช้ทำอะไร

| ชื่อในเกม | ใช้ตอน | เดาจากชื่อไฟล์ที่มีคำว่า |
|---|---|---|
| idle, walk, run | ยืน เดิน วิ่ง (ผสมกันตามความเร็วจริง ก้าวเท้าตามระยะทาง) | idle, walk, run |
| guard | ยกโล่ (ท่อนบน) ทับท่าเดิน | block + idle |
| light1-4 | ตีเบา 4 จังหวะ | slash, attack |
| heavy, finisher | ตีหนัก, ท่าปิดฉาก | attack, power, jump attack |
| skill1, skill2 | หมัดสามดาว, ดาวตกกระแทก | kick/punch, spin/360 |
| dodge | หลบ | roll, dodge |
| hit, guardbreak | โดนตี, การ์ดแตก | impact, hit, react |
| death | ตาย | death, dying |

ถ้าไม่มีท่าใด เกมจะยืมท่าที่ใกล้เคียง หรือขยับให้ด้วยโค้ด (เช่น ตีลังกาแทนท่ากลิ้ง)
ท่าโจมตีถูกเร่งหรือชะลอให้จังหวะที่มือขวาเร็วที่สุดในไฟล์ตรงกับจังหวะที่ Sim ตัดสินว่าฟันโดน

ตอนเกมเริ่ม Godot จะพิมพ์บรรทัด `[character]` ในแผง Output บอกว่าไฟล์ไหนถูกใช้กับท่าไหน
ถ้าเลือกผิด ให้คัดลอก `anim_map.example.json` เป็น `anim_map.json` แล้วแก้ชื่อไฟล์
ค่าเสริมของแต่ละท่า:
- `start`, `end`: ตัดช่วงของไฟล์ (วินาที)
- `hit`: วินาทีที่ดาบโดน ถ้าไม่ใส่ เกมจะหาจุดที่มือขวาเร็วที่สุดเอง
- `height`: ความสูงของตัวละครเป็นเมตร (ไม่ใส่ = ใช้ขนาดจากไฟล์)

## 4. หน้าตาแบบอนิเมะ

วัสดุทุกชิ้นของโมเดลถูกเปลี่ยนเป็น shader แบบ cel shade (`src/Toon.cs`)
- เงาเป็นขั้นชัด และใช้สีเงาจากค่า MToon ในไฟล์ VRM
- มีเส้นขอบรอบตัว และแสงขอบ
- หน้ากับตาไม่มีเงาแข็ง

ดาบและโล่สร้างจากรูปทรงพื้นฐาน ติดกับกระดูกมือขวาและแขนซ้าย

ผมกับกระโปรงแกว่งตามค่า spring bone ในไฟล์ VRM (`src/SpringBones.cs`) และตัวละครกะพริบตาทุก 2-5 วินาที

## ข้อจำกัดตอนนี้

- ยังไม่เปลี่ยนสีหน้าตามสถานการณ์ (มีแค่กะพริบตา)
- ไฟล์ในโฟลเดอร์นี้ไม่ถูกเก็บใน git (ดู `.gitignore`) เพราะท่าจาก Mixamo ห้ามแจกจ่ายไฟล์ดิบ
- โฟลเดอร์นี้มีไฟล์ `.gdignore` ให้ editor ข้ามการ import ไฟล์ .fbx (เกมอ่านไฟล์ตรงจากดิสก์) จึงยังไม่รองรับการ export เกมเป็นแอป
