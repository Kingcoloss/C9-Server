# บัลลังก์ที่แปด · demo การต่อสู้ 3D (phase 0)

ต้นแบบ action RPG 3D มุมกล้องหลังตัวละคร ที่เล่นได้ทั้งระบบต่อสู้ และ netcode แบบจำลองในเครื่องเดียว เพื่อให้ลองดูว่าท่าหลบหรือกันที่กดตามภาพบนจอได้รับการตัดสินถูกต้องไหม เมื่อ ping สูงขึ้น

## ใน demo มีอะไร

- ภาพ 3D มุมกล้องหลังตัวละคร
  - หมุนกล้องด้วยเมาส์ และเดินตามทิศที่กล้องหัน
  - การโจมตีจะล็อกเป้าศัตรูที่อยู่ใกล้กลางจอให้เอง (มีลูกศรสีขาวเหนือหัวเป้า)
  - วงเตือนท่าของศัตรูวาดลงบนพื้นสนาม
  - ฉากเป็นสนามประลองกลางซากวิหาร มีบัลลังก์ว่างตั้งอยู่ด้านเหนือ
- ด่านเดียว: หมาป่าหนาม 3 ตัว แล้วตามด้วยบอส "ราชาหมึก" ซึ่งมีท่าทุบ ท่าหลอก หนวดกวาด และบ่อหมึก
- ระบบต่อสู้ ได้แก่
  - ตีเบาต่อได้ 4 จังหวะ และตีหนัก
  - หลบ กัน หลบพริ้ว และรับพริ้ว (ทำพริ้วแล้วได้จังหวะสวนกลับ)
  - ระบบกระแส สกิล 2 อย่าง และท่าปิดฉาก
- netcode จำลอง: server กับ client แยกกันอยู่ในโปรแกรมเดียว ส่งข้อมูลหากันผ่านท่อที่หน่วงเวลาตาม ping ที่เลือก (0, 80, 150 หรือ 250 ms)
  - client ทำนายการเคลื่อนที่ของตัวเองล่วงหน้า และแสดงภาพศัตรูย้อนหลัง 2 tick
  - server ตัดสินท่าหลบหรือกันตามภาพที่ผู้เล่นเห็นตอนกด เรียกว่า "การชดเชยความหน่วง" ซึ่งเปิดหรือปิดได้ระหว่างเล่น
- กด F2 เพื่อสลับไปมุมมอง 2D จากด้านบน ซึ่งใช้ตรวจ netcode ได้ละเอียดกว่า (ระบบต่อสู้ชุดเดียวกัน)
- สิ่งที่ยังไม่มี
  - โมเดลและแอนิเมชันจากศิลปิน (ตอนนี้ตัวละครประกอบจากรูปทรงพื้นฐาน ขยับด้วยโค้ด)
  - เน็ตจริง (UDP/TLS) เสียง ไอเทม และระบบบัญชีผู้ใช้

## ติดตั้งบน MacBook Pro M1 (ครั้งแรกใช้เวลาประมาณ 15 นาที)

1. **ติดตั้ง .NET SDK 8 สำหรับ Arm64**
   - ดาวน์โหลด macOS Arm64 Installer (.pkg) จาก https://dotnet.microsoft.com/download/dotnet/8.0
   - หรือติดตั้งผ่าน Homebrew ด้วย `brew install --cask dotnet-sdk` (จะได้รุ่นใหม่กว่า 8 ซึ่งใช้ได้เหมือนกัน)
   - เปิด Terminal แล้วพิมพ์ `dotnet --version` ถ้าขึ้นเลขรุ่นแสดงว่าติดตั้งสำเร็จ
2. **ติดตั้ง Godot 4.7 รุ่น .NET**
   - ดาวน์โหลดจาก https://godotengine.org/download/macos/ แล้วเลือก **Godot Engine - .NET** (รุ่นธรรมดาจะเปิดโค้ด C# ไม่ได้)
   - หรือติดตั้งผ่าน Homebrew ด้วย `brew install --cask godot-mono`
   - ลากไฟล์ไปไว้ในโฟลเดอร์ Applications
3. **แตกไฟล์ zip** ไว้ที่ไหนก็ได้ เช่น Desktop
4. **นำโปรเจกต์เข้า Godot**
   - เปิด Godot แล้วกด Import
   - เลือกไฟล์ `godot/project.godot` ในโฟลเดอร์ที่แตกไว้ แล้วกด Import & Edit
   - ครั้งแรก Godot จะ import ฟอนต์อยู่ไม่กี่วินาที
5. **Build แล้วเล่น**
   - กดปุ่ม Build (รูปค้อน) ที่มุมขวาบน ครั้งแรกต้องต่อเน็ตเพื่อโหลดแพ็กเกจของ Godot จาก NuGet
   - จากนั้นกดปุ่ม ▶ (Run Project) หน้าต่างเกมจะเปิดขึ้นมา

### ถ้ายังไม่ได้ติดตั้ง Godot ก็ลอง netcode ได้

```bash
cd prototype
dotnet run --project Eighth.Sim.Tests
```

คำสั่งนี้รันบอทที่กดปุ่มตามภาพบน client ทุก ping ทั้งตอนเปิดและปิดการชดเชย แล้วพิมพ์ผลว่า server ตัดสินตรงกับที่ผู้เล่นเห็นหรือไม่

## ปุ่ม

คลิกในหน้าต่างเกมหนึ่งครั้งเพื่อให้เมาส์ควบคุมกล้อง กด Esc เพื่อปล่อยเมาส์

| ปุ่ม | การกระทำ |
|---|---|
| เมาส์ | หมุนกล้อง |
| ล้อเมาส์ | ซูมกล้องเข้าออก |
| WASD | เดินตามทิศที่กล้องหัน |
| ลูกศรซ้าย / ขวา | หมุนกล้อง (ใช้แทนเมาส์ได้) |
| คลิกซ้าย หรือ J | ตีเบา (กดต่อเนื่องได้ 4 จังหวะ) |
| คลิกขวา หรือ K | ตีหนัก |
| Space | หลบ |
| Shift ค้างไว้ (หรือ L) | กัน |
| Q | หมัดสามดาว (พุ่งแล้วต่อย 3 ครั้ง) |
| E | ดาวตกกระแทก (ทนแรงตอนง้าง แล้วกระแทกรอบตัว) |
| F | ปิดฉากศัตรูที่เสียหลัก |
| 1 / 2 / 3 / 4 | ping 0 / 80 / 150 / 250 ms |
| C | เปิดหรือปิดการชดเชยความหน่วง |
| N | แสดงแผงเครือข่ายแบบละเอียด |
| G | แสดงตำแหน่งจริงบน server (เงาสีชมพู) |
| B | ให้บอทเล่นแทน (กดอีกครั้งเพื่อเล่นเอง) |
| F2 | สลับระหว่างมุมมอง 3D กับมุมมอง 2D สำหรับตรวจ netcode |
| R | เริ่มด่านใหม่ |
| H | ซ่อนหรือแสดงคำแนะนำ |

ออกจากเกมด้วยการปิดหน้าต่าง หรือกด Cmd+Q (ในมุมมอง 2D กด Esc ได้ด้วย)

**สีของวงเตือน**
- ทอง: หลบพริ้วหรือรับพริ้วได้
- แดง: กันไม่ได้ ต้องหลบ
- ม่วง: กันได้ แต่รับพริ้วไม่ได้

วงบนพื้นจะค่อยๆ เต็ม ถ้าหลบหรือยกการ์ดตอนวงใกล้เต็มจะได้ผล "พริ้ว" และชื่อท่าจะขึ้นเหนือหัวศัตรูระหว่างที่มันง้าง

## ลองอะไรดี (ใช้เวลา 5 นาที)

1. **กด 3 (ping 150) โดยเปิดการชดเชยไว้** รอให้หมาป่ากระโจน แล้วกด Space ตอนวงทองใกล้เต็ม
   - จะขึ้นคำว่า "หลบพริ้ว!"
   - บรรทัดมุมขวาบนจะบอกว่าผลตรงกับ server และ server รอกี่ tick (กด N เพื่อดูแผงเต็ม)
2. **กด C เพื่อปิดการชดเชย** แล้วลองแบบเดิม
   - ถึงจะกดทันตามภาพ server ก็จะตัดสินว่า "โดน"
   - เหตุผลคือ server ตัดสินตามเวลาของตัวเอง ซึ่งเร็วกว่าภาพที่เราเห็นราว 300 ms
3. **กด 4 (ping 250) แล้วเปิดการชดเชยกลับ**
   - ยังหลบพริ้วได้
   - แต่ server รอจนชนเพดาน 10 tick (333 ms) ซึ่งเป็นขอบเขตที่ตั้งไว้กันการโกง
4. **กด G** เงาสีชมพูคือตำแหน่งจริงบน server ณ ขณะนั้น จะเห็นว่าศัตรูบนจอช้ากว่าความจริงเล็กน้อย
5. **สู้กับบอส**
   - ท่าหลอก: วงจะเต็มแล้วค้างไว้ อย่ารีบหลบ
   - หนวดกวาด (วงแดงรูปพัด): กันไม่ได้ ต้องหลบ
   - เมื่อทำให้บอสเสียหลัก ให้เข้าไปใกล้แล้วกด F

## โหมดสาธิตที่บันทึกภาพเอง

บอทจะเล่นที่ ping 150 แล้วเปิดและปิดการชดเชยตามลำดับ บันทึกภาพหน้าจอฉากสำคัญ (หลบพริ้ว ปิดการชดเชย เงา server ท่าของบอส และตอนจบ) ลงในโฟลเดอร์ที่กำหนด แล้วปิดเกมเองเมื่อจบด่าน

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --path prototype/godot -- --autoplay --shots=$HOME/Desktop/eighth-shots
```

ถ้าเพิ่ม `--write-movie demo.avi --fixed-fps 30` ไว้ก่อน `--` Godot จะบันทึกวิดีโอด้วย

## โครงสร้างโฟลเดอร์

```
prototype/
├── Eighth.Sim/        ตรรกะเกมล้วน ไม่อ้างถึง Godot (ใช้ร่วมกันได้ทั้ง client และ server จริงในอนาคต)
│   ├── Config.cs      ตัวเลขปรับสมดุลทั้งหมด (เวลาท่า ดาเมจ ช่วงพริ้ว เพดานรอ)
│   ├── PlayerSim.cs   การเคลื่อนที่และท่าของผู้เล่น (deterministic สำหรับทำนายผลและย้อนสถานะ)
│   ├── Judging.cs     กติกาตัดสินท่าหลบหรือกัน ใช้ฟังก์ชันเดียวกันทั้งสองฝั่ง
│   ├── World.cs       โลกฝั่ง server: AI ศัตรู ประวัติย้อนหลัง และการชดเชยความหน่วง
│   ├── Net.cs         ท่อหน่วงเวลา, GameServer, GameClient (ทำนาย/แก้ตำแหน่ง/interpolate), LocalSession
│   └── Bot.cs         บอทที่กดปุ่มตามภาพบน client (ใช้กับปุ่ม B และโหมดสาธิต)
├── Eighth.Sim.Tests/  บอททดสอบแบบไม่มีหน้าจอ
└── godot/             โปรเจกต์ Godot 4.7 (.NET) ที่สร้างฉากทั้งหมดด้วยโค้ด
    ├── main3d.tscn    ฉากเริ่มต้น (3D)
    ├── main.tscn      มุมมอง 2D สำหรับตรวจ netcode
    └── src/
        ├── Main3D.cs      กล้องหลังตัวละคร การรับปุ่ม และการผูกภาพ 3D เข้ากับ GameClient
        ├── Actors3D.cs    โมเดลผู้เล่น หมาป่า และบอส พร้อมท่าทางที่ขยับด้วยโค้ด
        ├── Art3D.cs       วัสดุ ชิ้นส่วนรูปทรง และสนามประลองกับบัลลังก์
        ├── Ground3D.cs    วงเตือนท่าบนพื้นและแนวฟันของผู้เล่น
        ├── Overlay3D.cs   หลอดเลือดศัตรู ชื่อท่า ตัวเลขดาเมจ ที่ลอยตามตำแหน่งในโลก 3D
        ├── Hud.cs         แผงผู้เล่น หลอดบอส บรรทัดเครือข่าย และคำแนะนำ (ใช้ร่วมกันทั้ง 3D และ 2D)
        ├── GameHost.cs    ส่วนที่ทั้งสองมุมมองใช้ร่วมกัน
        ├── Autopilot.cs   โหมดสาธิตที่บันทึกภาพเอง
        └── Main.cs, ArenaView.cs, Fx.cs   มุมมอง 2D
```

## ถ้าเจอปัญหา

- **Godot บอกว่าหา .NET SDK ไม่เจอ:** ติดตั้ง SDK ตามขั้นที่ 1 แล้วปิดและเปิด Godot ใหม่ ถ้าติดตั้งด้วย `brew install dotnet` (แบบ formula ไม่ใช่ cask) Godot อาจหาไม่เจอ ให้ใช้ไฟล์ .pkg แทน
- **Build ไม่ผ่านเพราะหา `Godot.NET.Sdk/4.7.2` ไม่เจอ:** การ build ครั้งแรกต้องต่อเน็ต
- **ใช้ Godot คนละรุ่น:** ควรใช้ 4.7.x ถ้าใช้รุ่นอื่น ให้แก้เลขรุ่นในบรรทัดแรกของ `godot/EighthThroneDemo.csproj` ให้ตรงกับรุ่นของ editor
- **เมาส์หายไปจากจอ:** เกมจับเมาส์ไว้เพื่อหมุนกล้อง กด Esc เพื่อปล่อย
- **ตัวอักษรไทยเป็นกล่องสี่เหลี่ยม:** ใช้เมนู Project > Reload Current Project เพื่อให้ Godot import ฟอนต์ใหม่
