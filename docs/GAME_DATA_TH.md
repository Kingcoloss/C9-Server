## 1. Current State (สำหรับส่งต่อให้ model/คนอื่น)

| รายการ | สถานะ |
|---|---|
| `src/C9.GameData` | **เสร็จเฟส 1 (data layer)** — model 15 ตาราง, migration แรก, services บัญชี/ban/ตัวละคร/rates/event/maintenance/ประกาศ/import JSON เดิม |
| `tools/C9.GameData.Design` | design-time host สำหรับ `dotnet ef` (ไม่ถูก ship) |
| `tests/C9.GameData.Validation` | 6 offline cases + 11 PostgreSQL cases, **ผ่าน 17/17 (111 assertions)** |
| `db/migrations/game-data.sql` | idempotent SQL script จาก migration — ทดสอบ apply ซ้ำ 2 รอบบน DB ว่างผ่าน (16 ตาราง) |
| เชื่อม `C9.Server` (CharacterLobby → DB) | **ยังไม่ทำ** — รอประสานกับงานข้อ 3 (Server/Portal) |
| หน้า Portal (`C9.Portal.Accounts`, `C9.Portal.World`) | **เสร็จ** — API + หน้าเว็บ, ทดสอบ 11/11 ดู [GAME_PORTAL_MODULES_TH.md](GAME_PORTAL_MODULES_TH.md); รอเสียบเข้า host `C9.Portal` |
| แยกบัญชีจาก login packet (type 12036) | **ยังไม่ทำ** — รอ decoded packet trace ของงาน 3.1 |
| ทดสอบบน Windows ของเจ้าของ | **ยังไม่ได้รัน** — ทดสอบใน Linux container (.NET SDK 10.0.115, PostgreSQL 16) |

ความเสี่ยง/ข้อจำกัดที่รู้:
- ทดสอบกับ PostgreSQL 16 ไม่ใช่ 18 (schema ใช้ฟีเจอร์ที่มีตั้งแต่ 13+ เช่น citext, jsonb, `GENERATED BY DEFAULT AS IDENTITY`)
- `Gold`, `Exp`, `Items`, `Ledger` มีตารางแล้ว แต่ game server ยังไม่มีระบบเหล่านี้ จึงยังไม่มี service แก้ไขทรัพย์สิน
  (ตั้งใจ — ดู design §7: ห้ามเปิดแก้ inventory/gold ก่อน server รองรับ)
- Password policy 8–128 ตัวอักษร (PBKDF2-SHA256 210,000 รอบ); บัญชี `local` สร้างแบบปิด password login

## 3. วิธีใช้

```powershell
# รัน validation แบบ offline (ไม่ต้องมี DB)
dotnet run --project tests/C9.GameData.Validation -- --offline

# รันครบกับ PostgreSQL (role ต้องสร้าง database ได้; ระบบสร้าง DB ชั่วคราวแล้วลบเอง)
$env:C9_DB_ADMIN_CONNECTION = "Host=127.0.0.1;Port=5432;Username=c9;Password=...;Database=postgres"
dotnet run --project tests/C9.GameData.Validation

# สร้าง migration ใหม่หลังแก้ model แล้ว export SQL
dotnet tool restore
dotnet ef migrations add <Name> --project src/C9.GameData --startup-project tools/C9.GameData.Design --output-dir Migrations
dotnet ef migrations script --idempotent --project src/C9.GameData --startup-project tools/C9.GameData.Design -o db/migrations/game-data.sql
```

ใน host (Portal/Server):

```csharp
builder.Services.AddC9GameData(Environment.GetEnvironmentVariable(GameDataServiceCollectionExtensions.ConnectionVariable)!);
await app.Services.MigrateGameDataAsync();   // หรือ apply db/migrations/game-data.sql ใน compose
```

Import ตัวละครเดิม (Lab) เข้าบัญชี `local`: `LegacyImporter.ImportCharactersAsync(path, context)` รันซ้ำได้ (ข้ามชื่อที่มีแล้ว)
ไม่แก้ไฟล์ต้นทาง

## 4. การควบคุมตาม ISO/IEC 27001 / 9001 / 29110

| ข้อกำหนด | วิธีที่ทำในโค้ด | หลักฐาน (test case) |
|---|---|---|
| ป้องกัน SQL injection | LINQ/parameter เท่านั้น; LIKE escape; sort แบบ whitelist; analyzer EF1002 + TreatWarningsAsErrors | "search treats input as data" |
| Audit log ทุกการเปลี่ยนแปลงของ operator (27001 A.8.15) | `OperatorContext` (operator, reason, request id) บังคับ; audit อยู่ใน transaction เดียวกับการแก้ | "account create ... audit", "edit with stale version ..." |
| ไม่เก็บความลับใน log | audit ของ password reset/create ไม่มี password หรือ hash | "account create ... audit" |
| รหัสผ่าน (27001 A.8.5) | PBKDF2-SHA256 210k รอบ, salt ต่อบัญชี, constant-time compare, ป้องกัน timing ของชื่อที่ไม่มี | "password hash verifies and rejects", "login verification" |
| Integrity / concurrency | xmin optimistic concurrency; FK RESTRICT; soft delete; check constraints | "edit with stale version", "soft delete ..." |
| Idempotency | `RequestId` unique ใน audit_log; retry คืนผลเดิม | "account create ... idempotent", "export and import" |
| Recovery | snapshot ตัวละครก่อนทุก edit (`ops.character_snapshots`) | "edit with stale version ... snapshot" |
| Traceability (29110) | requirement A1–A5, A9, A11–A14, W1–W2, W4–W6 ใน design → service ในตารางถัดไป | — |

| Requirement (design) | Service / method |
|---|---|
| A1 บัญชีหลายบัญชี | `AccountService.CreateAsync/SearchAsync/UpdateAsync/ResetPasswordAsync/VerifyLoginAsync` |
| A2–A4 ตัวละคร, แก้, ลบ/กู้ | `CharacterService.ListAsync/CreateAsync/RenameAsync/MoveSlotAsync/UpdateAsync/SoftDeleteAsync/RestoreAsync` |
| A5 Ban/Suspend | `SanctionService.IssueAsync/RevokeAsync/RefreshExpiredAsync` |
| A11 Audit timeline | `ops.audit_log` (query จะอยู่ใน Portal module) |
| A12 โน้ต/แท็ก | `AccountChanges.Note/Tags` |
| A13 Snapshot | `CharacterService.SnapshotsAsync` (rollback = เฟส 2) |
| A14/A18 Export/Import/ย้ายบัญชี | `CharacterService.ExportAsync/ImportAsync` |
| W1/W2 Event + Rates | `WorldService.EffectiveRatesAsync/SetServerRatesAsync/SetAccountRatesAsync/CreateEventAsync/UpdateEventAsync/DeleteEventAsync` |
| W4 ประกาศ | `WorldService.AnnounceAsync/ActiveAnnouncementsAsync` |
| W5 Maintenance | `WorldService.MaintenanceAsync/SetMaintenanceAsync` |
| Migration ข้อมูลเดิม | `LegacyImporter.ImportCharactersAsync/ImportServerRatesAsync` |
